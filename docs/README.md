## The four buckets

These docs follow the [Diátaxis](https://diataxis.fr/) structure:

- **Tutorials** — learning-oriented. Start here.
- **How-to** — task-oriented. Recipes for specific goals.
- **Reference** — information-oriented. Specs, flags, tables.
- **Explanation** — understanding-oriented. Why, not how.

See [explanation/how-it-works.md](explanation/how-it-works.md) for the full architecture diagram.
